HAPPY BIRTHDAY WEBSITE — QUICK SETUP

1. Unzip the folder.
2. Open index.html in your browser to preview the website.
3. Add your photo:
   - Put the picture inside the "images" folder.
   - Name it exactly: your-photo.jpg
   - If your picture is PNG, either convert it to JPG or change the image filename in index.html.
4. Add the birthday song from YouTube:
   - Open the YouTube video.
   - If its URL looks like https://www.youtube.com/watch?v=abc123, its video ID is abc123.
   - In birthday-song.html, replace YOUR_YOUTUBE_VIDEO_ID with that ID.
   - The video must allow embedding. YouTube does not let a webpage play audio from every video; the embedded video will appear with its normal controls.
5. Keep all HTML files, style.css, script.js, and the images folder together.

PAGES
- index.html: birthday greeting and photo
- birthday-song.html: YouTube birthday song
- letter.html: long birthday letter

This uses only HTML, CSS, and basic JavaScript. Google Fonts are loaded online; if offline, fallback fonts will be used.
